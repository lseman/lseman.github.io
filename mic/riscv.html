SCHEMATIC / 01 Processor datapath Follow the signals. Understand the machine.

A five-stage implementation of the supported RV32I subset. Crossings are not connections; dots mark shared wire junctions. Wires show the last completed cycle; pipeline registers latch at its end. Scroll horizontally on smaller screens.

Blue: active dataPurple dashed: controlAmber dashed: forwardingGold bars: pipeline registers
Control travels with the instruction

Each latch carries a valid bit and the fields needed downstream. ID/EX carries operands, source/destination indices, PC, PC + 4, immediate and EX/MEM/WB controls. EX/MEM carries the execution result, store data, rd and MEM/WB controls. MEM/WB carries load/result data, rd and WB controls. Dashed bundles represent these fields; local control fan-out is abstracted.

Forwarding before operand selection

For each used source, choose EX/MEM first, then MEM/WB, then ID/EX. Require RegWrite and rd ≠ x0; never forward a load address. Forwarded rs2 feeds the branch comparator and store-data latch independently of the ALU immediate input. WB writes before ID reads in the same cycle.

Hold, bubble, or redirect

The hazard unit compares a load’s ID/EX.rd with the used IF/ID source indices. On a match, hold PC and IF/ID and clear ID/EX for one cycle. EX resolves branches and jumps: a redirect clears both younger instructions and fetches the target next cycle. The small control ports above are symbolic outputs of this logic; monitor wiring is omitted.

Model boundary: conceptual datapath, not a gate-level netlist. Separate single-cycle memories; no caches, compressed instructions, CSRs, interrupts or privilege modes. This lab stops and drains older work on an invalid data access or misaligned target instead of entering a trap handler. Running beyond the loaded program drains the pipeline. 04 / BUILD YOUR INTUITION

Small details. Big consequences.

How a classic 5-stage pipeline handles hazards and control flow.

01KEEP THE DATA MOVING

Data Hazards

Forwarding from EX/MEM and MEM/WB reduces stalls. Load-use still costs a bubble because the data arrives in MEM/WB.

02CHOOSE THE NEXT PATH

Control Hazards

Branches and jumps resolve in EX. If taken, both younger instructions in IF and ID are squashed. The target is fetched on the next cycle; there are no delay slots.

03READ. WRITE. REPEAT.

Memory

Separate instruction and data memories; aligned 32-bit words at byte addresses with lw/sw. Address = rs1 + imm. x0 is hardwired to 0.
