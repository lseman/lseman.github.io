00 · The big idea

One line of C, four layers down

An instruction set is a contract between software and hardware. Follow one array read from source code to silicon. The middle two layers belong to the ISA, so every RISC-V core agrees on them. The last layer is the microarchitecture, which each design is free to choose. Select a layer to open its section.

The ISA promises
  • 32 registers, with x0 always zero
  • what each instruction computes
  • the exact bit encoding of every instruction
  • how memory accesses may be ordered
The microarchitecture decides
  • how many pipeline stages there are
  • cache sizes and memory latency
  • whether and how branches are predicted
  • how many instructions run per cycle

Sections 01, 02 and 04 describe the contract. Section 03 shows one way to build hardware that keeps it.

04 · Encoding

32 bits, six formats

When present, rs1, rs2, and rd keep their bit positions across the base formats, simplifying decode. Signed immediates use instruction bit 31 as their sign bit. Change an operand to see the encoded word; selecting an instruction also opens its pipeline trace.
