COMMSLAB / TUTORIAL OLED

Uma tela para cada placa

Mostre o estado do transmissor e do receptor no display, a partir do seu próprio firmware.

Na bancada virtual, cada placa tem um OLED didático em modo texto: 21 colunas × 8 linhas. A API abaixo usa JavaScript. A seção final mostra como adaptar a ideia a um OLED físico SSD1306 de 128 × 64 pixels em C++/Arduino. O simulador não emula pixels, I²C, fontes ou o controlador SSD1306.

1. Escreva sua primeira mensagem

Acrescente estas chamadas ao setup() já existente da placa A. Não crie um segundo setup. Clique em Carregar A + B: a mensagem aparecerá no OLED de A. Repita em B, mudando o texto para identificar o receptor.

oled.clear();
oled.setCursor(0, 0);
oled.println("PLACA A / TX");
oled.println("Aguardando envio");
oled.display();

Este teste de tela não precisa transmitir um quadro nem implementar CRC. Os TODOs do rádio continuam sendo sua atividade.

2. Entenda o buffer e o cursor

API do OLED virtual, disponível em setup() e loop()
ComandoEfeito
oled.clear()Limpa o buffer e retorna o cursor a (0, 0).
oled.setCursor(coluna, linha)Posiciona em coluna 0–20 e linha 0–7. Usa células de texto, não pixels.
oled.print(valor)Escreve texto ou número a partir do cursor.
oled.println(valor)Escreve e passa ao início da próxima linha.
oled.display()Copia o buffer para a tela visível.

Sem display(), as alterações ficam no buffer. O conteúdo visível persiste entre ciclos. Recarregar firmware ou limpar a sessão zera a tela; parar mantém a última imagem. A atualização chega à interface quando setup ou loop termina com sucesso.

Após 21 caracteres, a escrita continua na próxima linha; depois da oitava linha, o restante é cortado. Não há rolagem automática. Cada chamada print/println aceita até 1024 caracteres. Prefira textos curtos e sem acentos para facilitar a migração para fontes de hardware.

3. Atualize valores sem deixar restos

Use uma função para redesenhar a tela inteira. Acrescente esta função ao programa e chame-a em seu próprio loop, depois de implementar o envio.

function mostrarTX(numero, tamanho) {
  oled.clear();
  oled.println("TRANSMISSOR A");
  oled.print("Sequencia: ");
  oled.println(numero);
  oled.print("Bytes: ");
  oled.println(tamanho);
  oled.display();
}
// No loop, use suas variaveis reais:
// mostrarTX(sequence, frame.length);

Limpar antes de redesenhar evita que um valor menor deixe caracteres antigos à direita. Para testar isso, escreva “1000” e depois “9” na mesma posição, primeiro sem limpar e depois limpando.

4. Mostre a decisão do receptor

Depois de implementar a verificação do quadro, use o resultado real do seu código para atualizar o OLED de B. A tela apenas informa a decisão: não calcula nem valida o CRC.

function mostrarRX(aceito, recebido, calculado) {
  oled.clear();
  oled.println("RECEPTOR B");
  oled.println(aceito ? "ACEITO" : "DESCARTADO");
  oled.println("RX: " + recebido.toString(16).padStart(4, "0"));
  oled.println("CRC: " + calculado.toString(16).padStart(4, "0"));
  oled.display();
}
// Chame somente apos obter os valores no seu verificador.
// mostrarRX(accepted, crcReceived, crcCalculated);

No replay, o loop de A não executa: seu OLED permanece como estava, enquanto B pode atualizar sua tela. As telas são independentes; escrever em A não escreve em B.

5. Leve a ideia ao OLED físico

Para um módulo SSD1306 I²C 128 × 64, instale as bibliotecas Adafruit SSD1306 e Adafruit GFX na IDE Arduino. Confirme o controlador, a alimentação, os pinos SDA/SCL e o endereço I²C do módulo da aula; outros controladores exigem outro driver. O exemplo assume endereço 0x3C, barramento Wire padrão e ausência de pino de reset dedicado. Ajuste conforme sua placa.

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);

void setup() {
  Serial.begin(115200);
  Wire.begin(); // Ajuste os pinos conforme a placa do laboratorio.
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("Falha ao inicializar OLED");
    while (true) { delay(100); }
  }
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 0); // No hardware, coordenadas em PIXELS.
  display.println("PLACA A / TX");
  display.println("Aguardando envio");
  display.display();
}

void loop() {
  // TODO: integrar a atualizacao da tela ao seu firmware de radio.
}

Ao integrar, reúna a inicialização em um único setup e preserve a configuração do rádio. No hardware, clearDisplay() limpa o buffer e display() envia a imagem ao módulo. setCursor(0, 16) usa pixels, enquanto oled.setCursor(0, 2) no simulador usa a terceira linha de caracteres. Não copie as coordenadas diretamente.

Consulte a documentação oficial do driver SSD1306 e os exemplos da biblioteca para conferir a montagem e a configuração do seu módulo.
