01 Motivation

Why coherent demodulation needs a phase-locked loop

Ordinary envelope-detector AM works because the carrier is transmitted along with the sidebands — the receiver can rectify and low-pass filter the signal without knowing the carrier's exact phase. Double-sideband suppressed-carrier (DSB-SC) AM throws the carrier away to save power, which means the receiver has to reconstruct it. That reconstruction has to match the transmitter's carrier in both frequency and phase — a few degrees of phase error already start to attenuate and distort the recovered signal.

The Costas loop, introduced by John P. Costas in 1956, solves exactly this problem. It is a closed-loop feedback system: it demodulates the signal and uses the demodulated output as an error signal to correct its own local oscillator, converging on the true carrier phase without ever needing a pilot tone.

Where you'll see this again
Everything here generalizes directly to BPSK/QPSK carrier recovery in digital receivers — the block diagram is identical, only the phase detector nonlinearity changes.
02 Signal Model

The DSB-SC signal

A baseband message \(m(t)\) is modulated onto a carrier of frequency \(\omega_c\) with no carrier term added:

$$ s(t) = m(t)\,\cos(\omega_c t + \theta) $$
θ is an unknown, slowly drifting phase offset — the thing we need to estimate.

If the receiver simply multiplied \(s(t)\) by a locally generated \(\cos(\omega_c t)\) and low-pass filtered, it would recover \(\tfrac{1}{2}m(t)\cos\theta\) — scaled by \(\cos\theta\). Any phase error attenuates the message, and at \(\theta = 90^\circ\) the output vanishes entirely. We need a way to drive \(\theta \to 0\) automatically.

03 Architecture

Costas loop block diagram

The trick is to build two mixers driven by quadrature copies of the local oscillator — an in-phase (I) branch and a quadrature (Q) branch — and multiply their low-pass filtered outputs together to form an error signal that is zero exactly when the loop is locked.

FIG. 1 — I/Q mixers feed low-pass filters; their product drives the loop filter, which steers the VCO. Lock ⇔ e(t) = 0.

Note the asymmetry that makes this a phase-locked loop rather than just a demodulator: the I branch delivers the recovered message, while the Q branch exists purely to sense phase error. At lock, \(Q(t)\to 0\) and \(I(t)\) carries the full message amplitude.

04 Loop Dynamics

Deriving the error signal

Let the VCO produce quadrature references at its current phase estimate \(\hat\theta\):

$$ v_I(t) = \cos(\omega_c t + \hat\theta), \qquad v_Q(t) = -\sin(\omega_c t + \hat\theta) $$

Multiplying the input \(s(t)=m(t)\cos(\omega_c t+\theta)\) by each and applying a low-pass filter to remove the \(2\omega_c\) term leaves:

$$ I(t) = \tfrac{1}{2}m(t)\cos(\theta-\hat\theta), \qquad Q(t) = -\tfrac{1}{2}m(t)\sin(\theta-\hat\theta) $$

Define the phase error \(\phi = \theta-\hat\theta\). The phase detector output is the product:

$$ e(t) = I(t)\cdot Q(t) = -\tfrac{1}{8}m(t)^2\sin(2\phi) $$
The message-squared factor is why Costas loops are sometimes called "squaring loops in disguise" — it's always non-negative, so it never flips the sign of the error.

For small phase error, \(\sin(2\phi)\approx 2\phi\), so \(e(t)\) is (up to a negative, message-dependent gain) proportional to the phase error itself — exactly what a linear feedback loop needs. The loop filter — typically a proportional-integral (PI) controller — smooths \(e(t)\) and integrates it into a frequency correction for the VCO:

$$ \frac{d\hat\theta}{dt} = K_p\, e(t) + K_i \int_0^t e(\tau)\,d\tau $$
Design note
\(K_p\) and \(K_i\) set the loop bandwidth and damping. Too high and the loop chases noise; too low and it can't track phase drift or acquire lock quickly. In the code below we parametrize them through a target loop bandwidth and damping factor, the standard way to design a 2nd-order PLL.

rx = tx + noise                         # what the receiver actually sees

import numpy as np
import matplotlib.pyplot as plt
from signal import t, message, rx, fs, fc
from costas import costas_loop

I_out, Q_out, err_out, phase_hist = costas_loop(rx, fs, fc)

fig, axs = plt.subplots(3, 1, figsize=(10, 8), sharex=True)

axs[0].plot(t, message, label="original message", alpha=0.6)
axs[0].plot(t, 2*I_out, label="recovered (2·I)", lw=1)
axs[0].set_title("Message recovery")
axs[0].legend(); axs[0].set_ylabel("amplitude")

axs[1].plot(t, err_out, color="tab:orange")
axs[1].set_title("Phase-detector error e(t) — should decay to ~0")
axs[1].set_ylabel("e(t)")

axs[2].plot(t, phase_hist, color="tab:cyan")
axs[2].set_title("NCO phase accumulator")
axs[2].set_xlabel("time (s)"); axs[2].set_ylabel("radians")

plt.tight_layout()
plt.savefig("costas_lock.png", dpi=150)
plt.show()

# ---- pass/fail check -------------------------------------------------
# RMS phase-detector error over the last 20% of samples must be small,
# i.e. the loop actually locked and stayed locked.
tail = int(0.8*len(err_out))
rms_err = np.sqrt(np.mean(err_out[tail:]**2))
print(f"steady-state |e(t)| RMS: {rms_err:.2e}")

LOCK_THRESHOLD = 5e-4
assert rms_err < LOCK_THRESHOLD, (
    f"Loop did not lock (RMS error {rms_err:.2e} >= {LOCK_THRESHOLD:.0e}). "
    "Check the TODOs in costas.py against Section 4 before asking for help."
)
print("LOCK ACQUIRED — pass.")

07 Gotchas

Common pitfalls when students build this

The 180° phase ambiguity
Because the error signal depends on \(\sin(2\phi)\), the loop has two stable lock points: \(\phi=0\) and \(\phi=\pi\). The loop may lock with the recovered message inverted in sign. This is fundamental to Costas loops (and to BPSK carrier recovery) — it's resolved at a higher layer, e.g. differential encoding, not by the loop itself.
Confusing loop bandwidth with the LPF cutoff
These are two different filters serving different purposes: lpf_cutoff_hz strips the 2·fc mixing product from I/Q; loop_bw_hz shapes how fast the VCO phase estimate reacts to the error signal. Students often set them equal and get either a sluggish demodulator or an unstable one.
Sample-rate vs. carrier-frequency ratio
If \(f_s\) isn't comfortably above \(2f_c\) (Nyquist) with headroom for the 2·fc image, the LPF can't separate the wanted term cleanly. In this teaching example \(f_s/f_c=20\), which is generous on purpose — try lowering it and watch the loop struggle.
Phase wrap-around
Forgetting to wrap phase_acc into \([-\pi,\pi]\) is harmless numerically (cos/sin are periodic) but makes the phase-history plot in Fig. useless for diagnosing lock — always wrap before plotting.
